# MongoDB 高手课

来源：[gitee.com/geektime-geekbang/geektime-mongodb-course](https://gitee.com/geektime-geekbang/geektime-mongodb-course)  
课程：[唐建法《MongoDB高手课》](https://time.geekbang.org/course/intro/253)（约 47 讲，讲解版本 **4.2.1**）

仓库是 **4 册课件 PDF** + 实验脚本（`helloworld` / `aggregation` / `replicaset` / `transaction` / `sharded-cluster` / `spark-demo`）。课件体积大、图多，下面按四章提炼可复习的点。

| 章 | 面向 | 仓库对应 |
|----|------|----------|
| 一 再入门 | 文档模型、CRUD、聚合、复制集、全家桶 | helloworld、aggregation、replicaset |
| 二 开发精通 | 模型设计、事务、Change Stream、最佳实践 | transaction |
| 三 分片与运维 | 分片、监控备份安全、索引性能、两地三中心 | sharded-cluster |
| 四 架构进阶 | 选型、替 Oracle、数据中台、Spark/ETL | spark-demo |

一句话：一起访问的数据放一起；高可用靠复制集，水平扩展靠分片键；单文档原子够用就别上多文档事务。
