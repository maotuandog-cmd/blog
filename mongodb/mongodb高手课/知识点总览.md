# MongoDB 知识点总览

对照 [geektime-mongodb-course](https://gitee.com/geektime-geekbang/geektime-mongodb-course) 与《MongoDB高手课》。课程按 4.2 讲，新版本细节以官方文档为准。

## 1. 它解决什么

相对 MySQL 一类：JSON/BSON 贴近对象，少一层 ORM；单机写入能力通常更好；复制集做 HA，分片做水平扩展。TJ 的对比：同样业务访问层，代码量往往能少一个数量级。

适合：多态、字段常变、读多写多、要横向扩展。不适合：强多表 JOIN、报表随便扫、强约束全靠数据库。

**全家桶**（记名字）：`mongod` 数据节点、`mongos` 路由、`mongo`/`mongosh` shell、Compass 可视化、Atlas 云、BI Connector、Kafka/Spark Connector、Ops Manager / Cloud Manager。

连接串跨语言通用：

```text
mongodb://host:27017/?minPoolSize=10&maxPoolSize=100
复制集: mongodb://h1,h2,h3/?replicaSet=rs0
```

`_id` 不指定就生成 `ObjectId`。CRUD：`insert_one` / `find_one` / `update_one` + `$set` / `delete_one`（`helloworld/`）。

## 2. 聚合（pipeline）

实验数据：订单嵌订单行 `orderLines[]`。管道是数组，一步一步往下流。**先 `$match` 再 `$group`**，才能用上索引。

| 阶段 | 干什么 |
|------|--------|
| `$match` | 过滤（尽量放最前） |
| `$project` / `$addFields` | 整形、抽月份 |
| `$unwind` | 拆数组（订单行） |
| `$group` | `$sum` / `$first` … `_id` 是分组键 |
| `$sort` | 排序；和 `$group` 组合可取每组 top1 |
| `$lookup` | 跨集合关联（能 embed 就少用） |

订单行 Top SKU 套路：`$unwind` → 按 `{state, sku}` `$group` → `$sort` → 再按 state `$group` 用 `$first`。仓库 `aggregation/lab-script.md`。

## 3. 复制集（HA 的基本盘）

一主多从，选举出 PRIMARY，写走主，读默认可主（生产读从要设 `readPreference`）。oplog 在 `local.oplog.rs`，从节点追 oplog。

本机三节点实验（`replicaset/lab-script.md`）：不同 `dbPath` / 端口，同一 `replSetName`，再 `rs.initiate`。看 `rs.status()`：`stateStr` PRIMARY/SECONDARY。

常用成员角色：

| 配置 | 作用 |
|------|------|
| `priority` 高 | 优先当主 |
| `priority: 0` + `hidden: true` | 隐藏节点：备份/分析，不接业务读、不选主 |
| `priority: 0` delayed | 延迟从，防误删 |
| 投票数 | 奇数投票成员，避免脑裂 |

生产：域名代替 IP；`bindIp` 不要裸奔公网；开认证。

## 4. 文档模型（第二章主线）

原则：**一起读的放一起**。16MB 文档上限，数组不能无限涨。

| | 嵌入 | 引用 |
|--|------|------|
| 关系 | 包含、一起查、一起改 | 独立生命周期、多对多、会无限增长 |
| 代价 | 重复、文档变大 | 多次查询或 `$lookup` |
| 原子 | 单文档更新天然原子 | 要跨文档才用事务 |

设计步骤（课里三步）：先按访问路径画基础结构 → 按工况（热点字段、数组基数）细化 → 套模式（Bucket、Extended Reference、Subset、Computed、Schema Version…）。

版本字段 `schemaVersion` 方便在线演进，不必一次 migrate 完。

## 5. 事务与隔离（`transaction/`）

复制集/分片上的多文档事务（4.x）。能单文档解决就不要开事务。

实验三个现象：

1. **快照读**：事务里 `readConcern: snapshot`。事务外已经 `update` 了，事务内 `find` 仍是开始时的样子。
2. **写冲突**：两个事务改同一文档，后提交的那个失败（WriteConflict），要重试。
3. **写等待**：事务占着文档，事务外的普通 `update` 会堵住，直到 `commit`/`abort`。

配套：`writeConcern: majority` 提交才算落盘到多数节点。读侧还有 `local` / `majority` / `linearizable`。

**Change Stream**：在复制集上订阅变更（insert/update/delete），做微服务缓存失效、同步下游。依赖 oplog。

## 6. 分片（水平扩展）

三件套：

```text
mongos  —— 路由，应用只连它
config  —— 元数据（必须是复制集，--configsvr）
shard   —— 每个分片本身是复制集（--shardsvr）
```

`sh.addShard(...)` 加入；`sh.enableSharding("db")` + `sh.shardCollection("db.coll", {key: 1|'hashed'})`。Balancer 自动挪 chunk。实验里 hashed `_id` 加第二片后，两个 chunk 会拆到两片上。

分片键一旦选定很难改（新版本有 refinable，课里按 4.2 视为慎重选择）：

| 类型 | 何时 |
|------|------|
| 范围 | 查询常带范围，注意单调键（时间、自增 id）会打在一片上 |
| hashed | 写入打散，范围查询变 scatter-gather |
| zone | 按地域钉在指定分片（两地三中心常用） |

查询尽量带分片键，否则广播到所有片。`wiredTigerCacheSizeGB` 同机多实例要下调，默认约 `(RAM-1GB)/2`，超了容易 OOM。主机名用域名，方便迁 IP。

## 7. 索引、性能、运维

索引：等值、排序、范围尽量被同一复合索引覆盖（ESR：Equality → Sort → Range）。数组字段是多 key 索引。不用的索引删掉，写入会维护每一条。

排查：`explain("executionStats")` 看 COLLSCAN vs IXSCAN；慢日志 `profiler`；监控连接数、脏页、oplog 窗口、复制延迟。

备份：`mongodump` / 文件系统快照 / Ops Manager。隐藏节点专门备份。恢复要考虑 oplog 时间点。

安全：认证 + 角色（RBAC）、TLS、`bindIp`、禁用 HTTP 接口、审计。实验为省事没开 `--auth`，生产必须开。

上线：先复制集，容量到了再分片；升级走复制集滚动（先从后主）。

## 8. 两地三中心 / 全球多写

两地三中心：多数派投票跨机房，避免单机房死掉选不出主。常见 3 投票节点落在两个城市 + 第三地仲裁/隐藏。写关注和读偏好按 RPO/RTO 调。

全球多写：课里讲多活思路（后续官方有 Atlas Global Cluster / Zone）。核心仍是 **数据按区放置 + 冲突策略**，不是无脑双主。

## 9. 架构选型（第四章）

- **替 Oracle/MySQL**：适合文档边界清晰、JOIN 少的业务；报表仍可旁路到数仓。
- **数据中台**：Mongo 当灵活的服务数据层，不是替 Hadoop。
- **Spark**：Connector 按 `secondaryPreferred` 读，聚合可下推 pipeline，结果 `writeConcern majority` 写回（`spark-demo`：按生日月份统计最爱颜色）。
- SQL 套件 / BI Connector / Compass / ETL（如课里生态工具）走分析，不在线库上跑大表扫。

## 10. 实验怎么对上知识点

| 实验 | 应记住的结论 |
|------|----------------|
| helloworld | URI、连接池、`$set`、自动 `_id` |
| aggregation | `$match` 在前；嵌套数组先 `$unwind` |
| replicaset | 同 replicaSet 名 + `rs.initiate`；hidden 必须 priority 0 |
| transaction | 快照看不到未提交/事务外已改；冲突要重试；锁会堵住普通写 |
| sharded-cluster | shardsvr + configsvr + mongos；hashed 片键 + balancer |
| spark-demo | 离线算用从节点读，结果写回 Mongo |

复习口诀：模型跟访问路径走；复制集保活、分片键保扩展；事务是最后手段。
