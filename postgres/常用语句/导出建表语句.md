
PostgreSQL（PG）导出建表语句，常用几种方式：

## 1. 导出指定表结构（推荐）

```bash
pg_dump -h 主机 -p 端口 -U 用户名 -d 数据库名 \
  -t 表名 \
  --schema-only \
  > table.sql
```

例如：

```bash
pg_dump -h 127.0.0.1 -p 5432 -U postgres -d testdb \
  -t user_info \
  --schema-only \
  > user_info.sql
```

生成内容包含：

- CREATE TABLE
    
- 字段类型
    
- 默认值
    
- 索引
    
- 序列
    
- 约束
    

不包含数据。

---

## 2. 导出整个数据库建表语句

```bash
pg_dump -U postgres -d testdb \
  --schema-only \
  > schema.sql
```

---

## 3. 只导出某个 schema

例如 `public`：

```bash
pg_dump \
-U postgres \
-d testdb \
-n public \
--schema-only \
> public.sql
```

---

## 4. 只导出 CREATE TABLE（不要索引、约束）

如果只想看表：

```bash
pg_dump \
-U postgres \
-d testdb \
-t user_info \
--schema-only \
--no-owner \
--no-privileges
```

---

## 5. 查看单表建表语句（psql）

进入：

```bash
psql -U postgres -d testdb
```

查看表结构：

```sql
\d 表名
```

例如：

```sql
\d user_info
```

查看详细：

```sql
\d+ user_info
```

不过这不是标准 SQL。

---

## 6. 导出所有表结构 + 注释

推荐生产环境：

```bash
pg_dump \
-U postgres \
-d testdb \
--schema-only \
--no-owner \
--no-privileges \
--verbose \
> db_schema.sql
```

---

## 7. Docker 中 PostgreSQL

如果 PG 在容器：

```bash
docker exec -t pg_container \
pg_dump -U postgres -d testdb --schema-only \
> schema.sql
```

---

## 8. 单独获取某张表 DDL（SQL 查询）

PG 本身没有 MySQL 那种：

```sql
SHOW CREATE TABLE;
```

可以用：

```sql
SELECT 
    'CREATE TABLE ' || tablename || ' (...);'
FROM pg_tables
WHERE tablename='user_info';
```

但不完整，不推荐。

---

### 运维场景建议

备份结构：

```bash
pg_dump -U postgres -d dbname \
--schema-only \
--no-owner \
--no-privileges \
-F p \
-f db_schema.sql
```

恢复：

```bash
psql -U postgres -d newdb < db_schema.sql
```

如果是迁移数据库，建议直接用 `pg_dump --schema-only`，不要手工拼 DDL。
