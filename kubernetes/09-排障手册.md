## 1. 分层顺序（先定层再动手）

```text
1. 集群 API / 节点 Ready
2. 命名空间与 RBAC（能否 get/list）
3. 调度（Pending）
4. 镜像拉取（ImagePullBackOff）
5. 启动与探针（CrashLoopBackOff）
6. 服务与网络（通 Pod 不通 Service / DNS）
7. 存储（PVC Pending、挂载失败）
```

## 2. 节点 NotReady

```bash
kubectl get nodes
kubectl describe node <名>   # Conditions: MemoryPressure / DiskPressure / NetworkUnavailable
# 上节点：
sudo systemctl status kubelet containerd
sudo journalctl -u kubelet -e
# CNI：
ls /etc/cni/net.d
kubectl get po -A | rg -i 'cilium|calico|flannel|coredns'
```

常见：CNI 未装、运行时挂了、磁盘满、证书过期（控制面）。

## 3. Pod Pending

`kubectl describe pod` → Events：

| 线索 | 方向 |
|------|------|
| Insufficient cpu/memory | 加资源或降 requests；看其它占用量 |
| node affinity / taint | 标签、污点、容忍 |
| PVC not bound | SC/CSI/PV |
| unbound immediate PersistentVolumeClaims | 存储 |

## 4. ImagePullBackOff

```bash
kubectl describe pod <名>   # Failed to pull image ...
```

查：镜像名/tag、仓库连通、`imagePullSecrets`、节点 DNS、限流。

## 5. CrashLoopBackOff

```bash
kubectl logs <pod> --previous
kubectl describe pod <名>   # OOMKilled？探针失败？Exit code
```

查：启动命令、配置/密钥缺失、权限、内存 limit、liveness 过猛。

## 6. Service 不通

1. Pod Ready？Endpoints/EndpointSlice 有地址？  
2. 同命名空间 `curl <podIP>:port`  
3. `curl <clusterIP>:port` / DNS `svc.ns.svc.cluster.local`  
4. NetworkPolicy 是否默认拒绝（Calico/Cilium）  
5. kube-proxy / Cilium kube-proxy-replacement 状态  

详见容器网络 03/05。

## 7. kubeadm 初始化失败

```bash
sudo kubeadm init phase preflight   # 或看 init 报错
# 端口占用、swap、cri-socket、已有 /etc/kubernetes
sudo kubeadm reset -f   # 干净重来前确认无生产数据
```

## 8. 最小验收（装完/变更后）

```bash
kubectl get nodes
kubectl -n kube-system get po
kubectl run netcheck --image=busybox:1.36 --restart=Never -- sleep 3600
kubectl exec netcheck -- nslookup kubernetes.default.svc.cluster.local
kubectl delete pod netcheck
```
