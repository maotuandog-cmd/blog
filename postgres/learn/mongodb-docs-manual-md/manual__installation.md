# Install MongoDB

MongoDB is available in two server editions: *Community* and *Enterprise*.

This section contains information on installing MongoDB.

- To upgrade your current deployment to MongoDB 8.3, see [8.3 Upgrade Procedures.](/docs/manual/release-notes/8.3#std-label-8.3-upgrade)

- To upgrade to the latest patch release for your current version, see [Upgrade to the Latest Self-Managed Patch Release of MongoDB.](/docs/manual/tutorial/upgrade-revision#std-label-upgrade-to-latest-revision)

## MongoDB Installation Tutorials

**Note:**

If you installed MongoDB using a package manager such as APT, DNF, or Zypper, use your operating system's package management tool to upgrade within [Patch Releases](/docs/manual/reference/versioning#std-label-versions-patch-release). For [Major](/docs/manual/reference/versioning#std-label-major-releases) and [Minor](/docs/manual/reference/versioning#std-label-minor-releases) releases, follow the installation instructions for your OS.

MongoDB installation tutorials are available for both Community Edition and Enterprise Edition on the following platforms:

### Community Edition

To install MongoDB Community Edition, see [Install MongoDB Community Edition](/docs/manual/administration/install-community#std-label-install-mdb-community-edition). Select your platform and follow the instructions for your operating system.

### Enterprise Edition

To install MongoDB Enterprise Edition, select the tutorial for your platform and follow the instructions for your operating system.

| Platform | Tutorial |
| --- | --- |
| Linux | [Install MongoDB Enterprise Edition on Red Hat or CentOS](/docs/manual/tutorial/install-mongodb-enterprise-on-red-hat#std-label-install-mdb-enterprise-redhat-centos)[Install MongoDB Enterprise Edition on Ubuntu](/docs/manual/tutorial/install-mongodb-enterprise-on-ubuntu#std-label-install-mdb-enterprise-ubuntu)[Install MongoDB Enterprise Edition on Debian](/docs/manual/tutorial/install-mongodb-enterprise-on-debian#std-label-install-mdb-enterprise-debian)[Install MongoDB Enterprise Edition on SUSE](/docs/manual/tutorial/install-mongodb-enterprise-on-suse#std-label-install-mdb-enterprise-suse)[Install MongoDB Enterprise Edition on Amazon Linux](/docs/manual/tutorial/install-mongodb-enterprise-on-amazon#std-label-install-mdb-enterprise-amazon-linux) |
| macOS | [Install MongoDB Enterprise on macOS](/docs/manual/tutorial/install-mongodb-enterprise-on-os-x#std-label-install-enterprise-macos) |
