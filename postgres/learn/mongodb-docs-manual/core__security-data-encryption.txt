Docs Menu Ask MongoDB AI Docs Home Docs Home Docs Home Encryption Copy page MongoDB provides the following encryption methods: In-Use Encryption Encryption at Rest TLS/SSL (Transport Encryption) In-Use Encryption MongoDB provides two approaches to In-Use Encryption: Queryable Encryption Client-Side Field Level Encryption. For more information, see In-Use Encryption. Encryption at Rest Encryption at rest, when used in conjunction with transport encryption and security policies that protect relevant accounts, passwords, and encryption keys, can help ensure compliance with security and privacy standards, including HIPAA, PCI-DSS, and FERPA. For more information, see Encryption at Rest. TLS/SSL (Transport Encryption) MongoDB supports TLS/SSL (Transport Layer Security/Secure Sockets Layer) to encrypt all of MongoDB&#x27;s network traffic. TLS/SSL ensures that MongoDB network traffic is only readable by the intended client. For more information, see TLS/SSL (Transport Encryption).
