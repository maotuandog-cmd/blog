###1 分割压缩包
```
#方式1 zip
# 假设你已经安装了需要的所有工具，并且在正确的目录下。 
# 1. 解压 .tar.xz 文件到一个临时目录（如果需要的话）
tar -xf dcp_v5.0.3_x86_64.tar.xz -C /path/to/temp/dir/ 
# 2. 将解压出来的目录或文件重新打包成一个zip文件 
cd /path/to/temp/dir/ zip -r dcp_v5.0.3_x86_64.zip ./* 
# 3. 使用zip命令分割这个zip文件为每个480M的小文件
zip -s 480m dcp_v5.0.3_x86_64.zip --out dcp_split.zip

# 合并分割的zip文件为单个文件 
zip dcp_split.z01 -s=0 --out dcp_combined.zip 
# 如果你是从.zip文件开始的，现在可以解压它
unzip -d ./ dcp_combined.zip
```

### mount

你现在是 CentOS/RHEL 系的 root 环境，直接执行：

```bash
yum install -y nfs-utils
```

安装完成后确认：

```bash
which mount.nfs
which mount.nfs4
```

然后再挂载：

```bash
mount -t nfs4 192.168.161.197:/data/backup /jpsoft/data/databackup/mongo/
```

验证：

```bash
df -hT /jpsoft/data/databackup/mongo/
mount | grep mongo
```

### 如果 `yum install` 已经显示 Complete!

你贴出来的：

```text
Complete!
```

很可能就是刚才安装 `nfs-utils` 的结果。那就不用重复安装，直接检查：

```bash
rpm -q nfs-utils
ls -l /sbin/mount.nfs*
```

正常应该能看到类似：

```text
/sbin/mount.nfs
/sbin/mount.nfs4
```

然后：

```bash
mount -t nfs4 192.168.161.197:/data/backup /jpsoft/data/databackup/mongo/
```

如果安装完 **还是同样的 `bad option`**，把下面三条的输出贴给我：

```bash
rpm -q nfs-utils
ls -l /sbin/mount.nfs*
cat /etc/os-release
```

我可以继续判断是 **NFS 客户端没装、NFSv4 路径不对，还是服务器端 export 配置问题**。
