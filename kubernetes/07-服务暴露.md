## 1. Service 类型（使用向）

| type | 用途 |
|------|------|
| ClusterIP | 集群内稳定 VIP（默认） |
| NodePort | 每节点开端口进集群（调试/简单外曝） |
| LoadBalancer | 云上要 LB；裸金属需 MetalLB 等 |
| ExternalName | DNS 别名 |

```bash
kubectl expose deploy/nginx --name=nginx-svc --port=80 --target-port=80
kubectl get svc,endpointslices -l app=nginx
# 或
kubectl apply -f - <<'EOF'
apiVersion: v1
kind: Service
metadata:
  name: nginx-node
spec:
  type: NodePort
  selector:
    app: nginx
  ports:
  - port: 80
    targetPort: 80
    # nodePort: 30080  # 可省略，自动分配
EOF
```

验证：

```bash
kubectl run -n default curl --rm -it --image=curlimages/curl -- restart=Never -- \
  curl -sS http://nginx-svc/
# NodePort: curl http://<任一节点IP>:<nodePort>/
```

## 2. Ingress 最小落地

Ingress **只是规则**；必须有 **Ingress Controller**（ingress-nginx / Traefik / Cilium Gateway 等）。

概念 YAML：

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: nginx-ing
  annotations:
    # 视控制器而定，例：nginx.ingress.kubernetes.io/...
spec:
  ingressClassName: nginx
  rules:
  - host: nginx.example.local
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: nginx-svc
            port:
              number: 80
```

裸金属常见：Controller 用 NodePort/hostNetwork/MetalLB 暴露 80/443，再把域名指过去。

Gateway API 是后续方向，见容器网络 04；本期先跑通 Ingress 即可。
