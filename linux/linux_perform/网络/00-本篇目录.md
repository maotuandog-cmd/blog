学习顺序：先 TCP/IP 栈和收发路径，再指标与基准，再案例，最后按层优化。

一句话串起来：先分清包卡在 ring / skb / Socket / conntrack 哪一层；`ss` 看队列，`sar -n DEV` 看 PPS，小包 + 高 PPS 先想软中断和 conntrack。应用侧 epoll + `TCP_NODELAY` 比盲目加大缓冲更常奏效；流量型 DDoS 到了机器上只能缓解。
