# 05 · 存储入门

> 承接 [[04-配置与密钥]]。官方：[Persistent Volumes](https://kubernetes.io/docs/concepts/storage/persistent-volumes/) · [Storage Classes](https://kubernetes.io/docs/concepts/storage/storage-classes/)

## 1. 三角关系

```text
Pod 声明 volume → 引用 PersistentVolumeClaim (PVC)
PVC 绑定 PersistentVolume (PV)
StorageClass 决定「动态」如何供应 PV（CSI 驱动）
```

- **emptyDir**：随 Pod 生死，适合缓存  
- **hostPath**：绑节点路径，实验可用，多副本/迁移危险  
- **PVC**：有状态应用正路  

## 2. 静态 PV + PVC（本地实验）

```yaml
# pv.yaml
apiVersion: v1
kind: PersistentVolume
metadata:
  name: pv-local
spec:
  capacity:
    storage: 1Gi
  accessModes: ["ReadWriteOnce"]
  persistentVolumeReclaimPolicy: Retain
  hostPath:
    path: /mnt/data
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: pvc-local
spec:
  accessModes: ["ReadWriteOnce"]
  resources:
    requests:
      storage: 1Gi
```

Pod 中：

```yaml
volumes:
- name: data
  persistentVolumeClaim:
    claimName: pvc-local
```

```bash
kubectl apply -f pv.yaml
kubectl get pv,pvc
```

## 3. StorageClass（动态）

生产靠 CSI（NFS、云盘、Longhorn、Rook-Ceph 等）注册 StorageClass；PVC 写 `storageClassName` 即可自动建 PV。

```bash
kubectl get sc
kubectl get pvc -o wide   # Pending 时常是无 SC / 无 CSI / 访问模式不匹配
```

## 4. 访问模式速记

| 模式 | 含义 |
|------|------|
| RWO | 单节点读写 |
| ROX | 多节点只读 |
| RWX | 多节点读写（需后端支持） |
