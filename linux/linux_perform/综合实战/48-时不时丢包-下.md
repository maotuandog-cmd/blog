# 48 | 案例篇：服务器总是时不时丢包，我该怎么办？（下）

原文：[time.geekbang.org/column/article/85688](https://time.geekbang.org/column/article/85688)

接上讲：链路层 netem 删了，三次握手仍失败。继续查 **conntrack / iptables / 抓包**。

## conntrack

全局、不属于 netns，要在**宿主机**看：

```bash
sysctl net.netfilter.nf_conntrack_max     # 262144
sysctl net.netfilter.nf_conntrack_count   # 182 → 没满
```

## iptables

盯 filter 里 DROP/REJECT 的计数是不是 0：

```bash
iptables -t filter -nvL
# INPUT/OUTPUT 各有一条 statistic random probability 0.30 -j DROP
iptables -t filter -D INPUT  -m statistic --mode random --probability 0.30 -j DROP
iptables -t filter -D OUTPUT -m statistic --mode random --probability 0.30 -j DROP
```

删完 `hping3` 10/10 通。K8s Service 改不了目的 IP，也要查 netfilter 有没有加载。

## SYN 通、HTTP 不通

`curl --max-time 3` 超时，hping3 仍正常。tcpdump 看到三次握手，**没有 GET**，3s 后客户端 FIN。

`netstat -i`：RX-DRP=344，eth0 **MTU=100**。hping3 只发空 SYN；GET 带数据，veth **不会分片**，超 MTU 直接丢。改 `ifconfig eth0 mtu 1500` 后 curl 正常。

IP 可以分片，也可设 DF 不许拆；分片成本高，很多应用默认不分。Wireshark Flow Graph 看握手时序时注意源/目的别看反。

## 丢包检查清单

1. `netstat -i` / `ethtool -S` / `tc -s qdisc`
2. `netstat -s` 看重传、半连接重置
3. 宿主机 conntrack count vs max
4. `iptables -nvL` 看 DROP 计数
5. tcpdump：握手通但无 payload → 查 MTU
