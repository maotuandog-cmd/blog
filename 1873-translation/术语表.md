# 《1873》术语表

| English | 译法 | 说明 |
|---|---|---|
| House of Rothschild | 罗斯柴尔德家族银行／罗斯柴尔德家族 | 依具体语境区分机构与家族。 |
| Rothschild Frères | 罗斯柴尔德兄弟银行 | 巴黎分行的正式名称；首次出现保留英文。 |
| N. M. Rothschild & Sons | N. M. Rothschild & Sons | 伦敦分行正式名称。 |
| bond / bond market | 债券／债券市场 | 与股票、贷款区分。 |
| underwriting / underwriter | 承销／承销商 | 涉及保证政府筹得资金时，按原文说明担保义务。 |
| equity / shares | 股票／股份 | 与债券区分。 |
| government bonds | 政府债券 | “州政府债券”另行说明。 |
| sovereign borrower | 主权借款人 | 多指国家政府。 |
| default / repudiate debt | 债务违约／拒认债务 | 后者指明确否认偿付义务。 |
| bimetallism | 金银复本位制 | 第五章指法国货币制度。 |
| bullion | 金条／金银条块 | 依句中金属种类确定。 |
| indemnity / war contribution | 赔款／战争贡款 | 涉及 1871 年法国对德付款。 |
| syndicate | 银行财团 | 指联合承销债券的银行团体。 |
| land grant | 土地赠与 | 指政府向铁路公司授地。 |
| Union / Confederacy | 联邦／邦联 | 指美国南北战争双方。 |
| Panic of 1873 | 1873 年恐慌 | 前五章尚未正式展开；避免与长期萧条混同。 |
| first Great Depression | 第一次大萧条 | 指书中 1873 年后较长时期，与 1929 年后的“大萧条”区分。 |
| gold standard / deflation | 金本位制／通货紧缩 | 前五章非主要术语，留供后续章节沿用。 |
| Reconstruction | 美国南北战争后的重建时期 | 视上下文也可简称“重建时期”。 |

人名与地名按正文首次出现时的常用中文译法处理。原书个别日期或叙述若前后不一致，译稿保留原文，不擅自校改。

## 续译新增

| English | 译法 | 说明 |
|---|---|---|
| Gründerzeit | 创业时代 | 德国 1871 年后公司创办热潮。 |
| Creditanstalt | 奥地利信贷银行 | 安塞尔姆创办的奥地利股份制银行。 |
| Crédit Mobilier | 动产信贷银行／动产信贷公司 | 法国银行与美国铁路丑闻中的同名机构须按语境区分。 |
| margin / call loan | 保证金交易／活期贷款 | 对经纪人的活期贷款可被催收。 |
| tax farming | 包税制 | 奥斯曼政府将征税权交承包者。 |
| khedive / grand vizier | 赫迪夫／大维齐尔 | 分别为埃及统治者头衔与奥斯曼高官职位。 |
| Gilded Age | 镀金时代 | 第十章讨论词语的后起用法。 |
| Black Friday | 黑色星期五 | 需结合语境区分 1869 年纽约黄金恐慌与 1873 年维也纳股灾。 |
| Ottoman Public Debt Administration (OPDA) | 奥斯曼公共债务管理局 | 第十六章，债权国代表控制的偿债机构。 |
| Union Générale | 联合总银行 | 第十七章，邦图创办的法国银行。 |
| forward market / margin loans | 远期市场／保证金贷款 | 第十七章，区别结算日后的履约与买股融资。 |
| Free Silver | 自由铸银 | 尾声，美国金银复本位运动的口号。 |
| goldbugs / bimetallists | “黄金虫”／复本位主义者 | 尾声，两派货币政策支持者的称呼。 |
| Sherman Silver Purchase Act | 《谢尔曼白银购买法》 | 尾声，美国 1890 年立法。 |
