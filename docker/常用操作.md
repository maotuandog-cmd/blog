Docker 常用命令总表见 [[Docker 常用命令]]。

### 1 指定时间范围查询
```
docker logs --since "2026-10-31T08:00:00" \
            --until "2026-10-31T11:00:00" \
            容器
```

### 2 相对时间范围
```
docker logs --since 42m 容器      # 最近 42 分钟
```

### 3 跟随并截取
```
docker logs -f --tail 100 容器
```
