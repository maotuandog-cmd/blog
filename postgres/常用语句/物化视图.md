PostgreSQL 在 `psql` 中查看**物化视图（Materialized View）**和**外部表（Foreign Table）**常用命令如下。

---

# 一、查看物化视图（Materialized View）

## 1. 查看当前 schema 下物化视图

```sql
\dm
```

示例：

```text
              List of relations
 Schema | Name       | Type | Owner
--------+------------+------+-------
 public | mv_orders  | matview | postgres
```

---

## 2. 查看所有物化视图

```sql
\dm *.*
```

---

## 3. 查看物化视图定义

```sql
\d+ 物化视图名
```

例如：

```sql
\d+ mv_orders
```

查看：

- 字段
    
- 索引
    
- 存储信息
    

---

## 4. 查看创建 SQL

PG 没有直接 `SHOW CREATE MATERIALIZED VIEW`。

使用：

```sql
SELECT definition
FROM pg_matviews
WHERE matviewname='mv_orders';
```

例如：

```sql
SELECT *
FROM pg_matviews;
```

查看所有：

```text
schemaname
matviewname
owner
definition
```

---

## 5. 查看物化视图刷新时间

```sql
SELECT
    schemaname,
    matviewname,
    last_refresh
FROM pg_matviews;
```

注意：

部分 PG 版本没有 `last_refresh` 字段。

可以查：

```sql
SELECT *
FROM pg_matviews;
```

---

## 6. 刷新物化视图

普通刷新：

```sql
REFRESH MATERIALIZED VIEW mv_orders;
```

并发刷新：

```sql
REFRESH MATERIALIZED VIEW CONCURRENTLY mv_orders;
```

要求：

必须有唯一索引：

```sql
CREATE UNIQUE INDEX idx_mv_orders_id
ON mv_orders(id);
```
