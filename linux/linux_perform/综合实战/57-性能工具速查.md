# 57 | 套路篇：Linux 性能工具速查

原文：[time.geekbang.org/column/article/89306](https://time.geekbang.org/column/article/89306)

先确认指标，再选工具；已知工具就 `man`（看不懂再 `info`）。选工具还要看环境能不能装包、内核够不够新。Brendan Gregg 那张子系统工具图是总地图，真正下手按**指标分类**更快。

工具不是全部：原理才是核心；监控系统往往已经有基准，能从图上定位就别再手搓一遍。单机调到极复杂就改水平扩展。

## CPU

| 指标 | 工具 | 注意 |
|------|------|------|
| 平均负载 | `uptime` / `top` / `/proc/loadavg` | `uptime` 最简 |
| 系统 CPU | `vmstat` / `mpstat` / `top` / `sar` / `/proc/stat` | 动态看前三个，历史用 `sar` |
| 进程 CPU | `top` / `ps` / `pidstat` / `htop` / `atop` | `pidstat` 只显示在干活的 |
| 系统切换 | `vmstat` | 顺带 r/b |
| 进程切换 | `pidstat -w` | |
| 软中断 | `top`（si%）/ `mpstat` / `/proc/softirqs` | 后两个看每核每种 |
| 硬中断 | `vmstat`（in）/ `/proc/interrupts` | |
| 网络/I/O 辅证 | `dstat` / `sar`；抓包 `tcpdump` | |
| Cache | `perf stat` | 虚拟机里看不到物理 cache |
| CPU 个数 | `lscpu` / `/proc/cpuinfo` | |
| 热点/短命进程 | `perf` + 火焰图 / `execsnoop` | |
| 动态追踪 | `ftrace` / `bcc`（内核 ≥ 4.1）/ `systemtap` | |

先练熟：`top` + `vmstat` + `pidstat` + `perf`。

## 内存

| 指标 | 工具 | 注意 |
|------|------|------|
| 系统已用/可用 | `free` / `vmstat` / `sar` / `/proc/meminfo` | `free` 入门 |
| 进程 VIRT/RES/SHR | `ps` / `top` / `pidstat -r` / `/proc/<pid>/status` | |
| 地址空间 | `pmap` / `/proc/<pid>/maps` | |
| 进程 Swap | `top` / `status` 的 VmSwap | |
| 缺页 | `pidstat -r` | |
| 系统换页 | `sar -B` | |
| cache/buffer | `free` / `vmstat` / `sar` / `cachestat`（bcc） | |
| cache 命中 | `cachetop`（bcc） | |
| SWAP 空间 | `free` / `sar` | |
| si/so | `vmstat` / `sar` | |
| 泄漏 | `memleak`（bcc）/ `valgrind`（老内核） | |
| 某文件占了多少 cache | `pcstat` | 源码装 |

## 文件系统 / 磁盘 I/O

| 指标 | 工具 | 注意 |
|------|------|------|
| 容量 | `df` | inode 用 `df -i` |
| 页缓存/可回收 Slab | `/proc/meminfo` / `sar -r` / `vmstat` | |
| dentry/inode 缓存 | `slabtop` / `/proc/slabinfo` | |
| 盘：使用率 IOPS 吞吐 延迟 队列 | `iostat -d -x` / `sar -d` / `dstat` / `/proc/diskstats` | `iostat` 最常用 |
| 进程 I/O | `pidstat -d` / `iotop` | |
| 块设备事件 | `blktrace` + `blkparse` | |
| I/O 系统调用 | `strace`（单进程）/ `perf trace`（全机） | |
| 块 I/O 跟踪 | `biosnoop` / `biotop`（bcc） | |
| 动态追踪 | 同上 ftrace/bcc/stap | |

## 网络

| 指标 | 工具 | 注意 |
|------|------|------|
| 吞吐 BPS | `sar` / `nethogs`（进程）/ `iftop`（IP）/ `/proc/net/dev` | |
| 吞吐 PPS | `sar -n DEV` | |
| 连接数 | `ss`（比 `netstat` 快） | |
| 错误 | `netstat -s` / `sar -n EDEV` | |
| 延迟 | `ping`（ICMP）/ `hping3`（TCP） | |
| conntrack | `conntrack`；计数看 `nf_conntrack_count` / `_max` | |
| 路由 | `route` / `mtr` / `traceroute` | |
| DNS | `dig` / `nslookup` | |
| 防火墙/NAT | `iptables` | |
| 网卡 | `ethtool` | |
| 抓包 | `tcpdump` 现场抓，桌面用 Wireshark | |
| 动态追踪 | ftrace/bcc/stap | |

## 基准测试（按层）

| 层 | 工具 |
|----|------|
| 应用 | `ab` / `wrk` / `jmeter` / `sysbench` |
| 系统调用 | UnixBench |
| 文件系统/块 | `fio` / `dd` |
| 磁盘硬件 | `hdparm` |
| 网络栈 | `iperf` / `hping3` / `pktgen` / `ttcp` |
| 调度/内存 | `sysbench` / `perf bench` / `lmbench` |
| 路径连通 | `ping` / `mtr` / `traceroute` |

专栏里用过：I/O 用 `fio`，网用 `iperf`/`pktgen`，Nginx 用 `ab`/`wrk`。
