# 08 · 运维日常

> 承接 [[07-服务暴露]]。本 Lab（Cilium + master）速查：[[11-Lab-master常用命令]]  
> 官方：[kubectl Cheat Sheet](https://kubernetes.io/docs/reference/kubectl/quick-reference/) · [Monitoring, Logging, and Debugging](https://kubernetes.io/docs/tasks/debug/)

## 1. 上下文与命名空间

```bash
kubectl config get-contexts
kubectl config use-context <名>
kubectl get ns
kubectl config set-context --current --namespace=default
# 临时：-n <ns>
```

## 2. 看状态

```bash
kubectl get nodes -o wide
kubectl get po -A -o wide
kubectl top nodes          # 需 metrics-server
kubectl top pods -A
kubectl get deploy,sts,ds,svc,ing -A
```

## 3. 日志与事件

```bash
kubectl logs -f deploy/nginx
kubectl logs <pod> -c <sidecar> --tail=200
kubectl logs <pod> --previous
kubectl get events -n <ns> --sort-by=.lastTimestamp
kubectl describe pod <pod>
```

## 4. 进容器 / 转发 / 拷贝

```bash
kubectl exec -it <pod> -- sh
kubectl port-forward svc/nginx-svc 8080:80
kubectl cp <pod>:/path/file ./file
```

## 5. 变更与扩缩

```bash
kubectl scale deploy/nginx --replicas=3
kubectl edit deploy/nginx
kubectl apply -f app.yaml
kubectl diff -f app.yaml
kubectl delete -f app.yaml --grace-period=30
```

## 6. 节点侧（kubeadm 集群）

```bash
sudo systemctl status kubelet containerd
sudo journalctl -u kubelet -e --no-pager | tail -100
sudo crictl ps   # 需配置 /etc/crictl.yaml 指向 containerd sock
ls /etc/kubernetes/manifests   # 静态 Pod：apiserver 等
```

证书与配置路径（控制面）：

- `/etc/kubernetes/admin.conf`
- `/etc/kubernetes/pki/`
- `/var/lib/etcd/`（备份见 10）

## 7. 速查表

| 目的 | 命令 |
|------|------|
| 谁占资源 | `kubectl top` / describe |
| 为何没 Ready | describe Events + logs |
| API 是否通 | `kubectl get --raw='/readyz?verbose'` |
| 版本 | `kubectl version` / `kubeadm version` |
