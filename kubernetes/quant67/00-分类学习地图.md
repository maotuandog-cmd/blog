## 一句话

quant67 的 kubernetes 分类 = **网络深度（已蒸馏）** + **控制面底座（etcd / apiserver）** + **数据面/南北向内核** + **网格** + **运行时安全** + **Rook/CSI** + 少量行记。  
本目录做**地图 + 蒸馏**，不替代原文 16 篇制全书。

## 学习阶梯（建议）

```text
① 使用层        kubernetes/00–10（kubeadm）
② 网络层        容器网络/00–08  ←→  quant67 k8s-network
③ 控制面底座    本目录 01 etcd → 02 apiserver     ← 本期已蒸馏
④ 数据面深水    Cilium eBPF 内核 · Envoy Gateway  ← 地图占位，批次 B
⑤ 网格/安全/存储 Istio|Linkerd · Tetragon/Falco · Rook ← 按需
```
