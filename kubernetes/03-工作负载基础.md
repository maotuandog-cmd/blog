# 03 · 工作负载基础

> 承接 [[02-kubeadm安装集群]]。官方：[Deployments](https://kubernetes.io/docs/concepts/workloads/controllers/deployment/) · [Pods](https://kubernetes.io/docs/concepts/workloads/pods/)

## 1. 对象关系（够用版）

```text
Deployment  →  ReplicaSet  →  Pod(s)
                 ↑
           你很少手写 RS；改 Deployment 即可
```

- **Pod**：最小调度单位；可多容器共享 netns/卷  
- **Deployment**：声明副本数、镜像、滚动策略  

## 2. 最小发布

```bash
kubectl create deployment nginx --image=nginx:1.27 --replicas=2
kubectl get deploy,rs,pod -o wide
kubectl expose deployment nginx --port=80 --target-port=80   # 先出 ClusterIP，详解见 07
```

或 YAML：

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx
spec:
  replicas: 2
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.27
        ports:
        - containerPort: 80
```

```bash
kubectl apply -f nginx-deploy.yaml
```

## 3. 滚动更新与回滚

```bash
kubectl set image deploy/nginx nginx=nginx:1.27-alpine
kubectl rollout status deploy/nginx
kubectl rollout history deploy/nginx
kubectl rollout undo deploy/nginx
```

关键旋钮（spec.strategy.rollingUpdate）：`maxUnavailable` / `maxSurge`。

## 4. 探针（存活 / 就绪）

```yaml
livenessProbe:
  httpGet:
    path: /
    port: 80
  initialDelaySeconds: 10
  periodSeconds: 10
readinessProbe:
  httpGet:
    path: /
    port: 80
  initialDelaySeconds: 5
```

- **liveness** 失败 → 重启容器  
- **readiness** 失败 → 摘掉 Service 端点  

## 5. 常用查看

```bash
kubectl describe deploy nginx
kubectl describe pod <pod名>
kubectl logs <pod名> -c <容器名> --previous   # 崩溃前一轮
kubectl get events --sort-by=.lastTimestamp | tail
```
