# 1、查看外部表（Foreign Table）

PostgreSQL 外部表基于 FDW（Foreign Data Wrapper）。

---

## 1. psql 查看外部表

```sql
\det
```

输出：

```text
              List of foreign tables
 Schema | Name       | Server
--------+------------+--------
 public | remote_user | mysql_srv
```

---

## 2. 查看所有外部表

```sql
\det *.*
```

---

## 3. 查看外部表结构

```sql
\d+ 外表名
```

例如：

```sql
\d+ remote_user
```

显示：

- 字段
    
- Foreign Server
    
- Options
    

---

## 4. 查看外部表定义 SQL

```sql
SELECT
    n.nspname AS schema,
    c.relname AS table_name,
    s.srvname AS server,
    c.reloptions
FROM pg_class c
JOIN pg_namespace n
ON n.oid=c.relnamespace
JOIN pg_foreign_table ft
ON ft.ftrelid=c.oid
JOIN pg_foreign_server s
ON s.oid=ft.ftserver;
```

# 三、查看 FDW 信息

## 查看已安装 FDW

```sql
\dew
```

或者：

```sql
SELECT *
FROM pg_foreign_data_wrapper;
```

---

## 查看 Foreign Server

```sql
\des
```

或者：

```sql
SELECT
    srvname,
    srvoptions
FROM pg_foreign_server;
```

---

## 查看 User Mapping

```sql
\deu
```

或者：

```sql
SELECT *
FROM pg_user_mappings;
```

---

# 四、查询系统表方式

## 查物化视图

```sql
SELECT
    schemaname,
    matviewname,
    owner
FROM pg_matviews;
```

---

## 查外部表

```sql
SELECT
    n.nspname AS schema,
    c.relname AS foreign_table
FROM pg_class c
JOIN pg_namespace n
ON c.relnamespace=n.oid
WHERE c.relkind='f';
```

`relkind`：

|值|对象|
|---|---|
|r|普通表|
|m|物化视图|
|f|外部表|

# 五、导出物化视图/外表定义

### pg_dump

只导出定义：

```bash
pg_dump \
-d dbname \
--schema-only \
-t mv_orders
```

外表：

```bash
pg_dump \
-d dbname \
--schema-only \
-t remote_table
```

# 运维常用速查

|目的|命令|
|---|---|
|看表|`\dt`|
|看物化视图|`\dm`|
|看外表|`\det`|
|看视图|`\dv`|
|看定义|`\d+ 对象名`|
|看所有对象|`\d`|
|看 FDW|`\dew`|
|看外部服务器|`\des`|
|看用户映射|`\deu`|

如果是在做 **PG 数据迁移/巡检**，建议重点导出：

```sql
\dm *.*
\det *.*
\dew
\des
\deu
```

这几个可以完整掌握数据库里的物化视图和 FDW 外部依赖。
