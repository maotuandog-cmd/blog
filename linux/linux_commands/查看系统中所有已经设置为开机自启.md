你可以使用以下命令来查看系统中所有已经设置为开机自启（`enabled`）的服务：

  

Bash

```
systemctl list-unit-files --type=service --state=enabled
```

### 命令解释：

- **`list-unit-files`**：列出所有已安装的 systemd 单元文件及其开机启动状态。
    
      
    
- **`--type=service`**：只过滤出“服务”类型的单元（排除 mount、socket、target 等其他类型）。
    
      
    
- **`--state=enabled`**：只显示状态为 `enabled`（已启用开机自启）的服务。
    
      
    

### 补充常用命令

如果你不仅想看开启了自启的服务，还想看看当前正在运行（不管是否自启）的服务，可以使用：

  

Bash

```
systemctl list-units --type=service --state=running
```

如果你想检查**某一个特定服务**是否已经 enabled（比如 nginx）：

Bash

```
systemctl is-enabled nginx
```
