# 22 | 答疑：文件系统与磁盘有何区别？

原文：[time.geekbang.org/column/article/76675](https://time.geekbang.org/column/article/76675)

内存篇练习答疑。原理比工具版本重要：新系统上学，旧生产上指标仍对得上。

## 1. 回收和 OOM

内存紧了三步，前两步都走 LRU（`active` / `inactive` 两个链表，越靠尾越不常用）：

1. 收文件页（Cache）
2. Swap 收匿名页
3. 还不够 → OOM，按 `oom_score` 杀

```bash
cat /proc/meminfo | grep -i active | sort
dmesg | grep -i 'Out of memory'
```

收回来的页回到未使用池，给新申请用。

OOM 看的是 **虚拟内存**：申请的虚拟量 + 机器已用（used + buff/cache）超过物理内存就会走这条路。容器还受 cgroup limit 约束，容器 OOM ≠ 整机没内存。

估最小内存：跑起来用 `ps` / `smaps` 看，业务起来后再留余量。K8s 记得设 request/limit。

不开 Swap：**跑着的进程**自己的匿名页系统收不走，只能进程自己 `free` 或退出后系统放。Swap 也满了 = 内存耗尽，下一步就是 OOM。

## 2. 文件 vs 磁盘

磁盘是块设备，可分区；分区上建文件系统再挂载，才有普通文件。两者都能用 `open/read/write`，用 `ls -l` 看类型。

| | 普通文件 | 块设备（裸 I/O） |
|--|----------|------------------|
| 路径 | 经文件系统再到盘 | 跳过文件系统 |
| 缓存 | Cache | Buffer |

读写文件最终会落盘，但中间多了文件系统这一层。

## 3. 统计全部进程物理内存

**不要把 RSS 相加**——共享页（库、代码）会重复。用 **PSS**：私有 + 共享按进程数摊。

```bash
grep Pss /proc/[1-9]*/smaps | awk '{total+=$2} END {printf "%d kB\n", total}'
```

`smem` 也可以，加的必须是 PSS。Cache 是系统级的，单看进程 RSS 对不上 14G cache；用 `vmstat` / `cachetop` / `slabtop` 综合看。

## 4. CentOS 装 bcc-tools

要内核 ≥ 4.1。CentOS 7 常见做法：ELRepo 装 `kernel-ml`，重启确认 `uname -r`，再 `yum install bcc-tools`，把 `/usr/share/bcc/tools` 加进 PATH。头文件要跟内核版本匹配，否则缺 `.so`。

## 5. 斐波那契泄漏更好的修法

不必 `malloc` + `free`：结果放**栈上数组**，系统自动回收。少动态分配本身也是优化：栈、内存池、HugePage。
