# Nginx 核心知识（对照 100 讲课件）

来源：[gitee.com/geektime-geekbang/geektime-nginx](https://gitee.com/geektime-geekbang/geektime-nginx)  
课程：[陶辉《Nginx核心知识100讲》](https://time.geekbang.org/course/intro/138)（后扩充到约 155 讲）

仓库里是 **6 册课件 PDF** + `examples/` 配置。课件中文多为图，下面按六册结构提炼可复习的点，不拷幻灯原文。

| 课件 | 对应主线 |
|------|----------|
| 第一册 | 场景、发行版、编译、配置语法、命令行、静态站、反向代理入门、HTTPS 概念 |
| 第二册 | 进程模型、信号、reload/热升级、事件与 epoll、模块、内存池、红黑树 |
| 第三册 | HTTP 处理阶段、location、rewrite、变量、access、过滤模块 |
| 第四册 | listen/upstream、负载均衡、缓存、realip、SSL 细节、HTTP/2、gRPC、WebSocket、stream |
| 第五册 | 限流限连、open_file_cache、slice、性能与内核、stub_status |
| 第六册 | 安全链接、map/geo、内容改写、OpenResty/Lua、模块开发视角 |

配套配置在仓库 `examples/`（`locations.conf`、`proxy.conf`、`cache.conf` 等）。

一句话：Nginx 是 **master 管进程 + worker 事件驱动** 的反向代理平台；请求按 **11 个 HTTP 阶段** 走模块，性能靠 **少阻塞、连接复用、缓存、内核参数**，扩展靠 **模块和 Lua**。
