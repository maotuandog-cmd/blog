在 Linux 中过滤掉以 `#` 开头的行，最常用的方法是结合 `-v`（反向匹配）和 `^`（行首锚点）参数。

  

### 1. 基础命令（过滤以 # 开头的行）

Bash

```
grep -v "^#" filename
```

### 2. 进阶用法（日常查看配置文件的最佳实践）

通常在查看配置文件时，我们不仅想过滤掉注释（包括前面有空格的 `#`），还想把**空行**也一并过滤掉，让输出更整洁。你可以使用以下命令：

  

Bash

```
grep -Ev "^\s*#|^\s*$" filename
```

**参数说明：**

  

- `-v`：反转匹配（Invert match），即只输出**不匹配**该规则的行。
    
      
    
- `-E`：支持扩展正则表达式（Extended regexp），允许使用 `|` 等符号。
    
      
    
- `^`：匹配行的开头。
    
      
    
- `\s*`：匹配零个或多个空格/制表符。
    
      
    
- `$`：匹配行的结尾。
    
      
    
- `|`：正则表达式中的“或”。
