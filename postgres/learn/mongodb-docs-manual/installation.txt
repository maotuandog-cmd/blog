MongoDB Installation Tutorials Note If you installed MongoDB using a package manager such as APT, DNF, or Zypper, use your operating system&#x27;s package management tool to upgrade within Patch Releases . For Major and Minor releases, follow the installation instructions for your OS. MongoDB installation tutorials are available for both Community Edition and Enterprise Edition on the following platforms: Community Edition To install MongoDB Community Edition, see Install MongoDB Community Edition . Select your platform and follow the instructions for your operating system. Enterprise Edition To install MongoDB Enterprise Edition, select the tutorial for your platform and follow the instructions for your operating system.
