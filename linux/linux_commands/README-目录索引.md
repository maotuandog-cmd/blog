# linux_commands 目录索引 (MOC)

定位: Linux 常用命令的使用说明 — 一个命令一篇笔记,速查为主
与同级目录的分工:

  linux_commands/      单一命令的速查 (本目录)
  linux_/              GDB 工具专题 (9 章详解,linux_commands/gdb 命令.md 是入口)
  linux_perform/       故障排查 + 性能实战 (CPU / IO / 内存 / 网络)
  linux_stress_test/   压测 / 选型验证 (存储介质选型 + A-F 六大类)
