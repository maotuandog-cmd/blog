可以。你这个场景**最稳妥的办法不是一个个手工找“缺的包”**，而是在能联网的 **Sword** 上把依赖一次性解析、全部下载下来，再带到 **Hulbert**。

而且你已经有 KY10 镜像的话，优先级其实是：

**Hulbert 挂 ISO 本地源 > Sword 下载完整依赖 > 手工找 RPM。**

Kylin V10 的离线环境通常就是通过本地 ISO/本地 RPM 仓库让 DNF 做依赖解析；`createrepo` 可以把 RPM 目录生成可用的本地仓库。([Kubi](https://kubi.pub/2023/11/22/kylin-repos-machine/?utm_source=chatgpt.com "麒麟V10离线仓库机器构建步骤 — 庆庆的随笔"))

## 但是你这次有个非常重要的坑

**不要直接在 Sword 上执行上面的命令就结束。**

因为你前面已经出现了：

```text

python3
rpm-libs
```

这说明你的依赖里面存在**精确版本依赖**。

如果 Sword 下载成：


而 Hulbert 需要：


还是装不上。

所以下载之前一定要让 **Sword 使用和 Hulbert 一致的 KY10 仓库**。

那根本不用从 Sword 下载。

```bash

```

或者：

```bash
dnf install libaio-devel
```

# 如果 ISO 没有

这时候再去 Sword 下载。

但我建议不要只下载你报错列表里的“被需要”包。

例如你看到：

```text
libaio-devel
```

不要只下载：

```bash
dnf download libaio-devel
```

而是：

```bash
dnf download --resolve --alldeps \
    --destdir=/root/ky10-deps \
    libaio-devel
```

这样会把：

```text
libaio-devel
    ↓
libaio
    ↓
libc 等依赖
```

一起解析。

# 下载完后做成本地仓库

这是你这个内网环境最推荐的方式。

Sword：

```bash
mkdir -p /root/ky10-deps
```

下载：

```bash
dnf download --resolve --alldeps \
    --destdir=/root/ky10-deps \
    你需要的软件包
```

然后：

```bash
createrepo /root/ky10-deps
```

`createrepo` 会生成：

```text
/root/ky10-deps/repodata/
```

这样整个目录就可以作为离线 DNF 仓库。([Janettr](https://doc.janettr.com/install/kylin10-aarch64/v0/2d9b4f31-5e18-4f22-bc18-55a3f4fa3c9b/?utm_source=chatgpt.com "Step6—本地yum源配置 | TT Bigdata"))

把整个：

```text
/root/ky10-deps/
```

拷到 Hulbert，比如：

```text
/opt/ky10-deps/
```

Hulbert：

```bash
cat >/etc/yum.repos.d/offline.repo <<'EOF'
[offline]
name=KY10 Offline Packages
baseurl=file:///opt/ky10-deps
enabled=1
gpgcheck=0
EOF
```

然后：

```bash
dnf clean all
dnf makecache
dnf repolist
```

最后：

```bash
dnf install 你的目标软件
```

**不要再：**

```bash
rpm -ivh ./*.rpm
```
