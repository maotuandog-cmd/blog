风险提示
================================================================

- GDB 可读写目标进程任意内存 → 不要 attach 生产关键进程
- core dump 可能含敏感数据 → 传输加密
- record-full 慢 50-100 倍, 占大量内存
- btrace 需要 CPU 支持 Intel PT
- 改内存实验 (set var / set {int}) 仅用于诊断, 不能跑进生产

================================================================
术语表 (跨章)
================================================================

  DWARF              调试信息格式
  ptrace             Linux 进程调试系统调用
  inferior           GDB 术语, "被调试进程"
  breakpoint         断点 (int3 指令)
  watchpoint         观察点 (硬件/软件内存监视)
  coredump           进程崩溃时的内存快照
  pretty printer     GDB 内部自定义对象显示的机制
  gdbserver          远程调试服务端
  debuginfod         按需下载调试符号的协议
  scheduler-locking  GDB 在断点时是否让其他线程跑
  reverse debug      反向调试, "时间倒流"
  coredumpctl        systemd 的 core 管理工具
  record-full        GDB 软件录制 (支持反向)
  record-btrace      Intel PT 硬件录制
