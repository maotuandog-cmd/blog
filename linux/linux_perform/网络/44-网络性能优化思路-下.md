临时改 `sysctl`，持久化写 `/etc/sysctl.conf`。数字只是方向，按场景调。Nagle + Delayed ACK 会打架。NAT 上别开 `tcp_tw_recycle`（4.1 已删）；NAT 环境也别乱开 `tcp_timestamps`。

## 传输层 TCP

**TIME_WAIT 多**（主动关闭方才有；HTTP 短连接常见，1 万条不一定异常）：

- 加大 `tcp_max_tw_buckets`、`nf_conntrack_max`
- 缩短 `tcp_fin_timeout`（实际是 FIN-WAIT-2 → TIME_WAIT；TIME_WAIT 本身固定 2MSL≈60s）和 `nf_conntrack_tcp_timeout_time_wait`
- `tcp_tw_reuse=1` 让新连接复用端口
- 加大 `ip_local_port_range`（本机当**客户端**连别人时才吃端口）
- fd：`fs.nr_open` 单进程、`fs.file-max` 系统、`ulimit -n` 当前会话、systemd `LimitNOFILE`

**SYN Flood**：加大 `tcp_max_syn_backlog` **或** 开 `tcp_syncookies`（不要同时当两套用）；减小 `tcp_synack_retries`。

**Keepalive**：缩短 `tcp_keepalive_time` / `intvl` / `probes`。更好的是应用层池化连接、合并该关的请求。

## UDP

加大缓冲和本地端口范围；包长按 MTU 走，少分片。

## 网络层

```text
net.ipv4.ip_forward = 1          # NAT/Docker 转发
net.ipv4.ip_default_ttl = 64     # 加大会更耗
net.ipv4.conf.eth0.rp_filter = 1 # 反向校验，减伪造 IP
net.ipv4.icmp_echo_ignore_all = 1
net.ipv4.icmp_echo_ignore_broadcasts = 1
```

以太网 MTU 1500。VXLAN 多 50B → 交换机 1550 或虚机 1450。支持巨帧可到 9000。

## 链路层

- 硬中断：`smp_affinity` / irqbalance；软中断：RPS/RFS 把应用和软中断绑同核，提高缓存命中
- 卸载：TSO/UFO、GSO、LRO（**转发场景别开**）、GRO、RSS 多队列、VXLAN offload
- 网卡多队列、加大 ring/队列（吞吐↑延迟也可能↑）；`tc` 做 QoS

`NET_RX` 全堆在一个核：中断亲和性没配或绑错了。

## C10M

协议栈本身是负担 → DPDK 用户态轮询，或 XDP 进栈前处理。
